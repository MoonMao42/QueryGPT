# ReceiptBI 1.0.0

**将 CSV、Excel 和只读数据库转换为可核查、可编辑的业务报表。**

## 本次包含

- 自然语言与数据库、Excel 等进行只读交互，生成图表及汇总
- 完整分析过程，含重点和图表
- 按数据源 AI 生成语义层
- 转换为可编辑报表
- 导出前预览分页

<details>
<summary><strong>macOS 首次打开说明</strong></summary>

```bash
xattr -cr /Applications/ReceiptBI.app
```
